# Data availability and publication boundary

This repository distributes analysis code, aggregate tables, figures, reports, field definitions, and source checksums. It contains no raw clinical workbooks, patient-level cohorts, model matrices, linkage crosswalks, encounter-level extracts, or recordings. Pseudonymous study IDs are not a certified de-identification determination.

Full reproduction requires approved access to the original data. Contact the project investigators through established institutional channels; do not post patient details or access requests containing clinical information in GitHub issues. This repository cannot grant access or attest to institutional disclosure approval.

The public artifacts preserve the final scientific analysis supplied for this project. Prior draft analyses, meeting transcripts, personal internship documents, dependency caches, local logs, and bundled archives are excluded. Aggregate outputs include small counts; no minimum-cell suppression policy was supplied, and this release must not be represented as a formal disclosure review.

`.gitignore`, the explicit release manifest, and repository checks help prevent accidental additions. They do not replace human review of every future publication.
