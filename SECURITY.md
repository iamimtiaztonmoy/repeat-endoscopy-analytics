# Sensitive-data incidents

Do not report credentials, clinical records, or potentially identifying examples in public issues. If you discover an exposure, contact the repository owner through an established private channel and provide only the minimum description needed to locate it.

Deleting a file from the current branch does not remove earlier Git history. The owner should coordinate access restriction, history cleanup, and any required institutional incident response. Repository checks are preventive aids, not a certification that every file is safe to disclose.
