# Reproducibility

## Public verification

Run `python tools/validate_public.py` with Python 3.12 or newer. No third-party libraries or source data are needed. This checks the publication inventory and aggregate numerical consistency; it is not a full model rerun. CI runs this command on Linux.

## Restricted reconstruction

Use only an institutionally authorized environment. Obtain the original workbooks through the investigators' approved access process; this repository does not grant data access. Workbook paths and SHA-256 hashes are recorded in `documentation/source_manifest.csv` and the supplementary manifests.

The original scripts are preserved without changing scientific logic. Their relative-path convention requires the checkout at:

```
SOURCE_ROOT/
  Dataset/
  Research Project/
  outputs/
    repeat-endoscopy-analytics/   # this checkout
```

Use a **separate local working copy** for full reconstruction. The report builder regenerates README.md and other delivered files using the original internal-package template; do not commit those generated changes to the public repository. Generated patient data must remain local even when pseudonymized.

Create a Python 3.12 virtual environment and install the recorded dependencies:

```bash
python -m venv .venv
# Activate the environment using your platform's normal command.
python -m pip install -r code/requirements.txt
python code/rebuild_analysis.py --source-root /absolute/path/to/SOURCE_ROOT
python code/rebuild_supplement.py --source-root /absolute/path/to/SOURCE_ROOT
python code/rebuild_extended.py
python code/prepare_contacts.py
python code/run_cox.py
python code/verify_cox.py
python code/final_robustness.py
python code/build_deliverables.py
python code/validate_package.py
```

Replace the example source path with the real approved source root. The extended and contact scripts infer SOURCE_ROOT from the directory layout above. Local dependency fallbacks are optional. The requirements file reproduces the recorded analysis environment; dependency installation and a full source-data rerun were not repeated during repository packaging.

`create_word_reports.py` is an optional Word export step and additionally requires `python-docx`; its version was not recorded in the original analysis requirements. The delivered Word files are preserved as supplied.

## Evidence and provenance

`documentation/final_validation.json` and `cox_verification.json` are archived source-analysis evidence, not results generated by GitHub Actions. `documentation/public_manifest.json` records hashes for every file shipped in this public snapshot except itself. `code/validate_package.py` requires the restricted reconstruction and is deliberately not run in public CI.

Do not use old joined datasets as substitutes for the original relational workbooks. Preserve source-specific cohort membership, both EGD diagnosis parts, distinct-day consolidation, and the documented diagnosis-linkage keys.
